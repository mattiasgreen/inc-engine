# Generator Cycle Phase, Milestone Tiers, Fidelity Modes, and 2-Hour Sawtooth Pacing

To eliminate flat progression curves while keeping simulation analytical ($O(1)$) and browser rendering lightweight, the engine couples integer-Tick Generator periods with Milestone Tiers, configurable UI Fidelity Modes, and a 2-hour sawtooth optimal pacing calibration.

1. **Deterministic Cycle Phase and Integer-Tick Batch Payouts**: Rather than storing mutable per-generator timers (which would degrade offline catchup into an $O(N)$ discrete event queue), each Generator declares an integer `cyclePeriodTicks` ($P \in \{1, 2, 3, \dots\}$), modifiable by Period Compression upgrades. A Generator's **Cycle Phase** (`0.0` to `1.0`) is derived purely from `totalTicks`, `cycleRemainderMs`, and `effectiveCycleDurationMs`. When a Generator's effective frequency is below 1 Hz (`effectivePeriodMs > 1000`), single-tick advancement awards discrete **Batch Payouts** ($P \times \text{unitOutput} \times \text{owned}$) on ticks where `totalTicks % P === 0` so currency jumps coincide with the progress bar reaching 100%, while multi-tick analytical integration and $\ge 1\text{ Hz}$ production flow smoothly per Tick.
2. **1 Hz Overdrive State and GPU-Accelerated Fidelity Modes**: When a Generator's effective cycle period reaches or exceeds 1 Hz (`effectivePeriodMs <= 1000`), oscillating progress bars are replaced by a continuous energized **Overdrive State** glow. Progress bars animate via GPU-composited `transform: scaleX(...)` without layout reflows. Players can choose between `Full`, `Eco`, and `Minimal` **Fidelity Mode** presets or toggle individual rendering controls (Progress Bar Refresh Rate at 60 Hz / 10 Hz / Static, Overdrive Glow, Purchase Particle Bursts, and Card Pulse / Rarity Effects).
3. **Milestone Tiers (`m0` to `m4`) and Asset Convention**: Generators, Upgrades, and Characters progress through five rarity tiers: `m0` (Common, 0 bought, $1\times$), `m1` (Uncommon, 25 bought, $3\times$), `m2` (Rare, 50 bought, $6\times$), `m3` (Epic, 100 bought, $18\times$), and `m4` (Legendary, 250 bought, $60\times$). Entities expose canonical milestone asset paths (`./assets/<id>-m0.jpg` through `-m4.jpg`) via `data-milestone-tier` and `data-milestone-asset` attributes while falling back cleanly to base artwork paired with CSS rarity styling.
4. **Exponential Hellroad Guardrail and 2-Hour Sawtooth Optimal Pacing**: Generator `costGrowth` (`1.35` on `gen0`, `1.40` to `1.50` on higher generators) ensures that during Run 1 (first Prestige at ~120 minutes of optimal play), `gen0` naturally ascends from `m0` to `m1` (25 bought), whereas reaching `m2` (50 bought) without prestiging requires a multi-day "hellroad" grind. Across the 2-hour (`7,200s`) optimal playthrough, upgrades (Period Compression, Milestone Resonance, Cross-Generator Synergy, and Logarithmic Momentum) create sawtooth wait-time waves oscillating between ~20s rapid steps, ~60s tactical steps, ~3-4m major milestone payoffs, and ~7-8m epoch jumps.
