# Low-Glare Atmospheric UI and Smoked-Glass Controls

To guarantee readable controls over arbitrary full-bleed artwork while preserving deep genre immersion across multi-hour sessions without game-specific UI code, the engine's presentation layer enforces a **Smoked-Glass Scrim** control surface and declarative **Atmospheric Profile** tokens in `GameConfig.palette`.

1. **Smoked-Glass Scrim for Artwork-Agnostic Legibility**: Interactive controls (`.btn.primary`, `.btn.secondary`, `.btn-upgrade`) never use solid neon fills or transparent light tints. Instead, all action buttons use a dark smoked-glass surface (`rgba(0, 0, 0, 0.60)` background, crisp white `#ffffff` text, and `backdrop-filter: blur(6px)`) paired with a `1px solid` theme-tinted border and subtle inset glow when affordable, or a dimmed `rgba(0, 0, 0, 0.45)` fill with muted `rgba(255, 255, 255, 0.42)` text when unaffordable. Full-bleed artwork cards (`.card.upg-card`) combine a directional dark scrim with text-shadow haloing (`0 1px 4px rgba(0, 0, 0, 0.92)`) so bright artwork focal points never wash out copy or buttons.
2. **Low-Glare Surface Luminance Hierarchy**: Because incremental games are viewed for hours at a time, `GameConfig.palette` tokens enforce controlled luminance steps rather than maximum-saturation terminal contrast. Primary accents (`--primary`) are reserved for key focal indicators, border highlights, and progress fills, while body copy (`--text`), secondary copy (`--text-muted`), and structural borders (`--card-border`) use desaturated, low-glare tones tuned to the world's ambient lighting.
3. **Declarative Atmospheric Profiles (Zero Game-Specific UI Code)**: Immersion and genre mood ("extra everything": claustrophobic vignettes, eerie bioluminescent decay, arcane candlelight warmth, or orbital telemetry crispness) are expressed strictly through generic CSS custom properties in `GameConfig.palette` (`--viewport-vignette`, `--ambient-filter`, `--text-glow`, `--card-scrim`, `--border-style`, and font/spacing tokens). The UI shell (`index.html` and `src/ui/app.js`) remains 100% theme-agnostic and binds any `GameConfig` without per-game branches, while respecting the user's **Fidelity Mode** settings.
